| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, dangerous command bypass, or flaw that could permit accidental data destruction or secret leakage in production environments:

1. **Do not open a public GitHub issue.**
2. Send an advisory report to the maintainer via GitHub Security Advisories or email `egecagintepe@gmail.com`.
3. Include:
   - A description of the issue.
   - Sample command string or git diff payload that bypasses the guardian.
   - Expected vs actual safety classification.

We will acknowledge receipt within 48 hours and work with you on a coordinated fix.
